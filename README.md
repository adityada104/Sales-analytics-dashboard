# 📊 Sales Analytics Dashboard

An interactive and visually engaging **Sales Analytics Dashboard** built using Microsoft Excel to analyze sales performance, profitability, regional performance, and business growth.

## 🚀 Project Overview

This project transforms raw sales data into an interactive dashboard that helps users quickly understand key business performance indicators and identify important trends.

The dashboard uses Excel's data analysis and visualization features to provide a simple and user-friendly reporting experience.

## ✨ Key Features

- 📈 Sales Growth Analysis
- 💰 Profit & Profit Margin Analysis
- 🌎 Regional Sales Performance
- 📊 Interactive Charts & Visualizations
- 🎛️ Interactive Slicers
- 📅 Monthly Sales Analysis
- 📌 KPI Cards
- 🎨 Premium Dark-Themed Dashboard
- ⚡ Animated Sales Growth Visualization using VBA

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Excel Formulas
- VBA
- Data Visualization
- Data Analysis

## 📊 Dashboard Insights

The dashboard provides insights into:

- Total Sales
- Total Profit
- Profit Margin
- Regional Performance
- Monthly Sales Trends
- Sales Growth
- Business Performance
